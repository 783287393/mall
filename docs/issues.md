## #1 feat(store): 登录用户收藏夹及跨设备同步

- **状态**：Closed（`20a4da6` 后端 + `2e2da2b` 店面）
- **用户价值**：顾客在浏览商品时可把心仪商品收藏，登录后在任意设备/会话看到
  同一份收藏列表，减少“想买时找不到”的流失；收藏不占用库存，适合做购物车
  前的“暂存区”。
- **验收条件**：
  1. 匿名点击收藏跳转登录页，登录后回到原商品页；
  2. 登录顾客可收藏/取消收藏，心形状态与后端一致；
  3. `/wishlist` 页面按最新优先展示收藏商品（含价格与缩略图），支持移除；
  4. 收藏数据存储在 `wishlist_item` 表，重启后仍存在；
  5. 重复收藏/重复移除不产生重复记录或报错；
  6. 商品下架后收藏页自动隐藏该项（不报错）。
- **关联 PR**：#1（见 `docs/pr-review.md`），附测试证据
  `http/wishlist.spec.ts` 10/10 通过。
